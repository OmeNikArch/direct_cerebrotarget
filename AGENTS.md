# Правила проекта

- Перед существенной работой прочитать `PROJECT-CONTEXT.md`. Обновлять его, если меняются статус проекта, точки запуска, ключевые файлы или следующий шаг.
- Использовать Tailwind CSS для цветовой палитры и классов.
- Избегать типичного для ИИ стиля интерфейса: случайных градиентов, чрезмерного свечения и лишних декоративных элементов.
- Создавать компоненты для всех повторяющихся и базовых элементов интерфейса: кнопок, инпутов, чекбоксов и других контролов. Создавать составные компоненты, такие как хедер и футер, если они переиспользуются на нескольких страницах.
- Подписи секций и короткие eyebrow-labels писать обычным регистром, без uppercase, увеличенного letter-spacing и искусственного изменения интерлиньяжа.
- Не ставить точку в конце заголовков.
- Соблюдать отступы с шагом 4 пикселя.
- Делать адаптивность макета для десктопа, планшетов и смартфонов.
- Перед завершением работы проверять мобильную версию на корректность и работоспособность.
